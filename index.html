À propos de moi

Hello world,
Je suis BELGHERBI Donia, admise en Master Cybersécurité : du Edge au Cloud à l'Université de Lille, à la recherche d'une alternance de 24 mois à partir de septembre 2026.
Comprendre comment un système fonctionne, puis comment il pourrait céder : la rigueur, c'est ce qui transforme cette curiosité en réponse fiable. Lors de mon stage à l'EHU d'Oran, j'ai développé une application médicale manipulant des données de santé : authentification avec hachage (SHA-256), chiffrement des données (AES), gestion des rôles (RBAC) et journalisation des actions, déployée en environnement hospitalier réel.
Je poursuis cette démarche à travers mes projets personnels : un honeypot IoT collectant en direct de vraies tentatives d'intrusion depuis le cloud, et un scanner détectant les configurations AWS S3 exposées publiquement disponibles sur mon GitHub.
Rigoureuse et autonome, je m'entraîne régulièrement sur Root-Me et Hack The Box pour garder mes réflexes d'analyse affûtés.
– Donia

% cybersécurité

Honeypot-attack-observatory

Honeypot TCP simulant un objet IoT vulnérable par exemple : caméra de surveillance IP connectée, une serrure intelligente connectée, une ampoule connectée, une prise électrique intelligente, un thermostat connecté, une montre connectée, et encore beaucoup d'autres objets de notre quotidien, pour observer en direct de vraies tentatives d'intrusion. Déployé en continu sur une VM cloud, il capture chaque session dans des logs structurés exploitables pour de l'analyse d'attaque.

Technologies : Python, Telnet, Oracle Cloud, JSON Lines

Fonctionnalités :

  • Simulation d'un service Telnet exposé (port 2323) (et port 23 par déviation)
  • Logger dédié — chaque session capturée en JSON Lines
  • Déploiement continu sur VM Oracle Cloud (ARM)
Voir le projet sur GitHub

cloud-exposure-scanner

Scanner détectant des buckets AWS S3 mal configurés (lecture, écriture ou listing publics) en simulant un attaquant externe, sans SDK AWS uniquement des requêtes HTTP non authentifiées.

Technologies : Python, AWS S3, HTTP, JSON

Fonctionnalités :

  • Classes BucketScanner et ReportWriter, rapports au format .jsonl
  • Sévérité classée via un enum, configuration multi-buckets en JSON
  • Gestion des timeouts et des erreurs réseau
Voir le projet sur GitHub

ARES/DEMETER

ARES/DEMETER sont deux projets de jeu de plateau développé en équipe. Chaque jeu est constitué d’un plateau divisé en tuiles représentant des ressources (forêts, montagnes, pâturages, champs, mer), avec des bâtiments pouvant être déployés. Les joueurs collectent des ressources et réalisent des actions stratégiques à chaque tour. Le projet est conçu pour être extensible afin d'ajouter facilement de nouvelles fonctionnalités.

Technologies : Java, Git, Modélisation objet

Fonctionnalités :

  • Modélisation du plateau et des ressources
  • Gestion des bâtiments et de leur dimension
  • Système de collecte et d’échange de ressources
  • Déroulement du jeu basé sur des tours et actions limitées
  • Extensible pour intégrer de nouvelles règles ou îles
Voir le projet sur GitHub
